# 个人照片验收证据

日期：2026-11-10。关联 UC-12 补充范围 AC-13–17。

截图来自真实生产资源、临时 Notes 服务与测试账号。花朵和山景为测试生成图像。

- `desktop-photo-light@2x.png`：1440×900 浅色桌面。
- `desktop-photo-dark@2x.png`：1440×900 深色桌面。
- `mobile-photo-light@2x.png`：390×844 浅色手机。
- `mobile-photo-dark@2x.png`：390×844 深色手机。

照片选择后自动保存。更换与移除不提交显示名草稿。服务端解码 JPEG、PNG 或 WebP，处理照片方向，并居中生成 512×512 WebP。输出移除原始元数据。输入上限为 5 MiB 和 4000 万像素，拒绝动画。

HTTP 验收位于 `tests/account-avatar.test.ts`，共 14 项。覆盖格式、方向、裁切、元数据、边界、认证、跨站、账号隔离、旧版本撤销、失败回滚、兼容与重启。

浏览器验收位于 `tests/account-avatar-browser.test.ts`，共 8 项。覆盖真实文件选择、三处头像同步、显示名草稿保留、更换、移除、格式拒绝、响应丢失、人工重试、上传及会话刷新忙态、手机与账号切换。

集成 Agent 数据库功能后，`npm run build` 通过。`npm test` 的 25 项核心与 104 项 HTTP 测试通过。`npm run test:e2e` 的 69 项浏览器测试全部通过。

Chromium 不在请求检查中提供本例 File 上传体。测试读取真实保存的图像，并与所选图像的居中缩略图比较像素。此检查验证实际保存内容。

头像复用现有附件目录，包含在原有数据库与附件备份中。读取需要浏览器会话。替换和移除后，旧 URL 返回 404。不可变字节与历史备份沿用现有保留方式。

本轮在 macOS Chromium 验证。手机截图使用浏览器视口；未使用手机实机或真实个人照片。
