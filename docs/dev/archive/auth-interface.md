# 登录与注册界面优化

状态：本轮实现与验收完成，2026-11-04 归档。本文保留当轮方案与结果。当前系统说明见 [Atlas](../../atlas/README.md)。

日期：2026-11-04。关联 UC-02。用户要求优化截图中的登录页。

## 方向

保留浅暖灰背景、白色表单和蓝色动作。比较了分栏品牌展示与单列登录。选择单列表单，用户可直接进入笔记。品牌只保留 Notes 与笔记图标，不添加宣传区。

卡片宽400px，正文14px，标题24px。输入框与主操作42px，手机44px。通过间距、字重和颜色区分品牌、标题、字段与次级入口。

## 交互与边界

- 密码可显示或隐藏，切换不清除输入。
- 登录和注册使用同一结构。注册规则只在注册时出现。
- 次级入口位于卡片下方。保留创建账号与返回登录。
- 请求中禁用重复操作，并显示进度。失败保留字段。
- 保留原有认证、会话、注册开关及密码策略。
- 不增加未接入的找回密码或第三方登录。

复用卡片入场，按钮按下反馈，密码图标切换。减少动态设置禁用相关过渡。验收覆盖真实注册与登录、错误保留、显示密码、窄屏及键盘提交。构建通过。两个真实浏览器流程各三轮，6/6 通过。桌面与手机登录、注册均已查看，独立视觉评审接受本版。正式证据见 [登录界面交付记录](auth-interface-delivery.md)。
