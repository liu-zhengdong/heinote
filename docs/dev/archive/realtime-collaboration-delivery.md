独立复审发现新段在结构确认前输入时丢失历史。修复后，撤销先移除新输入，再撤销拆分。另有回归确认：协作者修改后缀后，结构撤销不发送部分请求，二进制、修订、代次和两端正文保持不变。

80 段、36000 字符的同机 Node 投影微基准，从 247 ms 降为 5 ms。缓存只保存派生读取结果，并在 Y.Doc 更新后失效。该数值不是浏览器端到端输入延迟。

## 交付边界

普通富文本使用 Yjs。分段、合段、删除与树移动仍采用事务和冲突拒绝。移除字段或复制改写文字的结构边界会建立新代次，并重置更早的文字撤销栈。结构补偿保留在独立历史中。

本轮不提供完整结构 CRDT、离线首次打开、多实例服务或跨设备撤销。中文系统候选窗口、其他浏览器与手机软键盘未单独验证。

部署测试以 macOS 本地和 Podman Linux ARM64 为实际范围。原生 Docker Engine、Compose 提供器、Windows、Linux AMD64 及远程 HTTPS 未单独实跑。

Agent 提供 HTTP REST。提案作者使用令牌所属账号身份。它不提供独立 Agent 账号、MCP 适配或完整操作审计。
