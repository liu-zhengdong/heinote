## 交付边界

当前服务采用单实例 SQLite。协作通过轮询更新。同字段冲突会被拒绝，并提供未保存草稿下载。当前不支持字符级 CRDT 共编或离线编辑。

邀请对象需要先注册。当前不依赖 SMTP，也不发送邮件邀请。公开附件须先迁入发布页面所在空间。

Agent 提供 HTTP REST。更新 `text` 会把正文替换为单段纯文本。只修改标题时应省略 `text`。原 Terminus 窗口命令不是当前的外部协议。尚未实现 MCP 适配和完整结构化块编辑 API。

已在 macOS 本地和 Podman Linux ARM64 验证。原生 Docker Engine、Compose 提供器、Windows、Linux AMD64 和远程 HTTPS 反向代理尚未单独实跑。部署配置使用标准 Node.js 24 和 Docker 格式，不能据此声称所有机器均已验证。

原始目录没有 Git 元数据。本轮没有创建 Git 提交。页面版本管理已实现，源码版本库仍由项目维护者决定。
