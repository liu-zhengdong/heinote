# ADR-002：富文本 CRDT 与结构事务

- 日期：2026-11-04。
- 状态：已采用。
- 关联：UC-03、UC-05、UC-06、UC-07 至 UC-10。
- 本决策替代 [ADR-001](0001-standalone.md) 的同字段冲突策略。独立部署和权限模型继续有效。

## 问题

原有字段 CAS 能拒绝覆盖，但不能合并同段输入。编辑器还支持跨页组合、分段、合段和空间迁移。只加入 WebSocket，不能解决这些动作的原子性。

## 选择

Yjs 拥有每页的富文本。SQLite 拥有结构、权限和用户检查点。HTTP 批次是统一写入口。WebSocket 只推送已提交快照。

曾比较两种结构：

| 方案 | 优点 | 本轮代价 |
| --- | --- | --- |
| Hocuspocus 自动同步完整 Y.Doc，ProseMirror 拥有正文 DOM | 成熟的富文本绑定 | 需重写跨页编辑与历史；默认延迟保存不能代替跨页事务 |
| 按页 Yjs 富文本，保留结构事务与原生编辑器 | 保留原有复杂块操作和单体部署 | 需维护 DOM 基础绑定；结构并发采用明确拒绝 |

采用第二种。使用 Yjs 的合并算法，不自写 CRDT 或 OT。

## 状态归属

| 状态 | 唯一所有者 | 其他表示 |
| --- | --- | --- |
| 已提交富文本 | `collaboration_documents.state` 中的 Yjs 二进制 | SQL 富文本字段和界面内容均为投影 |
| 块关系、排序、空间和权限 | SQLite 记录及成员表 | 编辑器读取模型 |
| 未确认操作 | 当前窗口请求队列 | Y.Doc 暂态结果、账号分区日志及恢复草稿 |
| 输入法预编辑 | 活动 DOM | 组合结束后产生一次操作 |
| 个人文字历史 | 窗口内的 Y.UndoManager | 不跟踪远端或 Agent origin |
| 结构及未建立 Y.Text 时的文字历史 | WorkspaceHistory | 明确受控的 CAS 补偿 |
| 用户版本历史 | 服务端 PageVersion | 不作为完整操作审计 |

原有合法文字接口也进入协调器。它们通过既有 Y.Text 的局部操作更新二进制。首次迁移可从 SQL 建立文档。重新连接、轮询和进程重启读取已有二进制。

## 提交顺序

1. 验证会话、令牌和当前页面权限。
2. 验证代次与结构动作的完整基础修订。
3. 在影子 Y.Doc 应用增量。
4. 验证字段集合、Y.Text 身份和记录模式。
5. 在同一 SQLite 事务保存文字、结构及投影。
6. 提交后返回结果，并向仍有权限的订阅者推送。

浏览器 WebSocket 不接受写操作。跨页提交使用一个事务和一个推送信封。失败批次不推送部分结果。请求 ID 覆盖完整批次。

## DOM 与历史边界

绑定捕获实际已呈现字符的相对身份。输入只修改已观察字符，保留未呈现的远端插入。组合输入期间不重写活动 DOM，结束后提交一次。

已有 DOM 基础失效时，绑定保留草稿。绑定不能换用新代次基础，重新解释旧 DOM。未变化的宿主可更新页面修订，但必须先确认同一 Y.Text、同一代次和相同已观察内容。

文字操作按实际字段是否已有 Y.Text 分配历史所有权。新段在结构确认前的输入使用受控记录历史。它不能同时被两套历史跟踪，也不能完全失去历史。

结构撤销等待前序写入确认，再构造补偿。结构历史检查所有原步骤路径。任一路径被其他参与者修改，整项拒绝。不能只恢复首段而留下已修改的后半段。

## 代次与恢复

移除富文本字段、复制并改写已有文字的拆分、版本恢复和空间迁移会建立新代次。仅增加空块或移动现有块可保留代次与文字身份。

同代次普通文字合并，不要求相等修订。结构动作比较包含文字的完整修订。版本恢复先保存当前检查点，并保留当前位置和分享范围。

永久拒绝后，浏览器保存整个待提交链，并暂停后续发送。账号分区请求日志支持重新打开。恢复界面支持下载完整数据，以及通过独立 Cookie API 保存私人文字草稿。旧时钟增量不换代次重发。

## 取舍

分段、合段和树编辑仍采用事务与冲突拒绝。它们不是完整结构 CRDT。建立新代次会清除更早的文字撤销栈。结构补偿保留在单独历史中。

本轮不提供离线首次打开、多实例服务或跨设备撤销历史。后续更换编辑框架时，仍须保留服务端权限、跨页原子性和落盘确认。

## 依据

独立验收验证了乱序提交、中文组合输入、个人撤销、重连、撤权、版本恢复、提案审核和结构补偿。已确认并修正结构确认窗口中的历史丢失与部分补偿问题。结果见 [实时共编交付记录](../dev/archive/realtime-collaboration-delivery.md)。
