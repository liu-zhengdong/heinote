# 实时共编

verified: 2026-11-04

多名用户和 Agent 可以编辑同一页面。正文、标题和表格单元格的普通富文本使用 Yjs 合并。分段、合段、删除和树移动由服务端事务处理。

## 编辑、撤销与恢复

| 场景 | 当前行为 |
| --- | --- |
| 同时输入 | 合并同段文字和格式，保留 emoji 与原子提及。服务端保存成功后推送结果。 |
| 中文组合输入 | 组合结束后提交一次。本窗口可用一次文字撤销移除该次输入。 |
| 个人撤销 | 只撤销本窗口的文字修改，保留其他窗口和 Agent 的修改。 |
| 已打开页面断线 | 允许继续输入。同代次重连后合并更新。首次打开应用仍需要网络。 |
| 关闭后重新打开 | 按账号保存的待提交日志支持恢复。提交前重新检查身份、权限和代次。 |
| 撤权或代次失效 | 暂停相交空间的后续写入，保留完整失败批次。其他独立空间继续保存。用户可下载完整修改数据，或将可读文字保存为私人草稿。 |
| 结构动作冲突 | 检查所有受影响页面的完整基础修订。基础过期时，整批拒绝。结构撤销也不能部分恢复。 |
| 恢复版本 | 先保存当前检查点。恢复保留页面位置和分享范围。 |

代次用于区分文字身份。移除字段、复制改写文字的拆分或版本恢复等操作会建立新代次。新代次重置更早的文字撤销栈。旧增量不能更换代次后再次提交。

## Agent 提案审核

Agent 可直接提交结构化操作，也可保存提案。用户从页头的“Agent 提案”查看修改，再应用或拒绝。协议与示例见 [Agent API](../agent-api.md)。

同段文字操作合并为一份行内对照。删除使用删除线，新增使用下划线和浅底。长段落可以展开全文。作者、时间和修改范围集中显示。格式、结构及历史提案保留操作明细。

仅当页面代次和完整修订与提案基础一致时，界面才显示文字对照。正文变化后，界面标明提案失效，并停用应用按钮。服务端执行最终权限和修订检查。

## 系统如何协作

Yjs 二进制保存已提交富文本。SQLite 保存结构、权限和历史。SQL 富文本字段是读取投影。服务端在同一事务中保存二进制、投影及相关记录。

HTTP 批次是统一写入口。WebSocket 只推送已经提交的状态。跨页操作使用一个事务。普通文字与结构补偿分别管理历史，新字段建立 Y.Text 前使用受控记录历史。

状态归属、提交顺序和取舍见 [ADR-002](../adr/0002-realtime-collaboration.md)。

## 支持边界与验证范围

当前不提供完整结构 CRDT、离线首次打开、多实例服务或跨设备撤销。结构并发可能被明确拒绝。

已有验收覆盖双浏览器乱序输入、中文组合事件、个人撤销、断线重连、草稿恢复、提案审核和容器持久化。系统输入法候选窗口、其他浏览器与手机软键盘未单独验证。尚未进入用户连续日用验证。
