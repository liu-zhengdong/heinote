# 团队知识库

用户从左下角用户名菜单切换个人空间和团队知识库。齿轮保留原账号设置。使用步骤见 [部署与使用说明](../../README.md#团队知识库)。

## 数据归属

知识库复用 `spaces`、`members`、`invitations` 和分空间记录。`knowledge_bases` 存放固定首页、简介、归档、排序和修订。存在该元数据才表示团队知识库。普通页面分享不改变类型。

固定首页是唯一根。其他页面位于首页子树。Store 在写入前检查原记录归属，并在事务内校验最终树。整棵子树也不能借助删旧写新迁出或迁入知识库。固定首页不能移动、归档或永久删除。

首页保留普通编辑器。目录与最近更新从当前记录生成。界面不保存另一份内容列表。页面、数据库、附件、Yjs、检查点和提案使用原机制。

## 权限与生命周期

邀请逐库接受，成员获得整库角色。站点管理员不会自动取得知识库内容权限。Owner 和管理员可以管理成员及永久删除页面。编辑者可以维护内容和共享排序。只读成员可以查阅。

归档后，服务端写检查和协作快照共同禁止内容写入。未接受邀请同时失效。Owner 可以恢复知识库，或向现有成员移交。移交更新空间所有者，并将原 Owner 改为管理员。非 Owner 可以退出。

团队库不提供公开链接。Agent 令牌的内容权限仍与账号角色取交集。知识库创建、设置、归档和移交只接受浏览器会话。管理请求使用请求 ID 去重，并提供当前账号的结果查询。修订冲突拒绝覆盖。

## 浏览器状态

单个 `WorkspaceDocument` 持有账号当前获准的数据。当前空间控制导航、默认新建位置和默认搜索范围。目录、收藏、图谱和回收站只显示当前空间。搜索可以显式覆盖所有获准空间。

每个账号在本机记住最近空间和页面。成员失去访问权后，文档移除对应投影。仍在途的旧读取通过目标集合和打开标记校验，不能重新安装已撤销投影。

写队列按原子批次的空间依赖排序。永久拒绝保留整批草稿，并暂停相交空间的后续批次。其他独立空间继续保存。跨空间结构事务仍保持整批提交或拒绝。旧 Yjs 增量不会更换代次重发。
