# Notes 系统说明

Atlas 面向需要了解 Notes 的读者。这里按主题说明当前能力、系统结构、使用入口和重要边界。

| 想了解什么 | 阅读入口 |
| --- | --- |
| 如何部署，账号、分享和历史有哪些能力 | [独立部署与基础能力](standalone.md) |
| 多人如何编辑，如何撤销和恢复，如何审核 Agent 提案 | [实时共编](realtime-collaboration.md) |
| 登录与注册如何操作，表单遵循哪些约定 | [登录与注册界面](auth-interface.md) |
| 品牌图标如何使用，正式素材在哪里 | [Notes 品牌图标](brand.md) |

具体安装步骤见 [部署说明](../../README.md)。外部接口见 [Agent API](../agent-api.md)。架构决策见 [基础架构](../adr/0001-standalone.md)和[共编架构](../adr/0002-realtime-collaboration.md)。

开发文档按 UC → dev 执行稿 → 验收 → dev 归档推进。已完成的执行稿与交付记录见 [开发文档入口](../dev/README.md)。归档保留当轮事实；当前能力以本目录的主题说明为入口。
