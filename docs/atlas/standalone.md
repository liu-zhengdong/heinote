# 独立部署与基础能力

verified: 2026-11-10

Notes 是独立部署的多人笔记应用。它使用 React、Node.js 24 和 SQLite。运行时无需 Terminus 平台、外部账号服务或外部数据库。

## 部署与数据

本地和容器使用同一个服务入口。单个服务实例保存账号、正文、附件、历史、邀请和令牌摘要。SQLite 保存附件元数据，图片与其他附件保存在数据目录的 `attachments/`。完整数据副本先在线备份数据库，再复制不可变附件，可以在服务运行时执行。恢复需要同时保留数据库与附件目录。

安装、配置和恢复步骤见 [部署说明](../../README.md)。当前采用单实例部署，多个实例不能同时写入同一数据目录。

## 用户可以做什么

| 能力 | 入口与行为 |
| --- | --- |
| 管理笔记 | 使用页面树、块编辑器和数据库视图。页面默认私有。 |
| 运行小应用 | `kind` 为 `app` 的页面在沙盒 iframe 中运行启用源码。应用页面就地嵌入宿主文档；仅绑定数据源的 `schema` 与 `rows.*` 经桥接可达。公开链接只下发应用名称，不返回源码。 |
| 管理账号 | 注册、登录和退出。首个账号成为站点管理员。管理员可管理账号，但不会自动取得他人的私有内容。 |
| 邀请协作者 | 在 Share 中邀请已注册账号。对方接受后取得对应角色，范围包含子页面。服务端检查读取、编辑和成员管理权限。 |
| 发布只读页面 | 在 Share 中创建公开链接。访客可读取所选页面树，所有者可撤销链接。公开附件须位于页面所属存储空间。 |
| 恢复历史 | 在 Page history 中读取和恢复检查点。恢复前保存当前内容，并保留位置和分享范围。 |
| 接入 Agent | 在账号面板创建只读或读写令牌。Agent 可在浏览器关闭时调用 HTTP API。实际权限取令牌权限与账号权限的交集。 |

普通富文本支持多人合并输入。离线恢复、撤销和结构冲突行为见 [实时共编](realtime-collaboration.md)。登录与注册的界面约定见 [账号界面](auth-interface.md)。

## 使用边界

邀请通过应用内账号接收，不发送邀请邮件。版本历史用于内容恢复，不提供完整操作审计。每页历史受 20 个版本、30 天和 10 MiB 的保留规则约束。

Agent 使用 HTTP REST。接口契约见 [Agent API](../agent-api.md)。当前未提供独立 Agent 账号或 MCP 适配。

本轮已通过 macOS 本地构建、核心与 HTTP 回归、18 项浏览器流程及 Podman Linux ARM64 容器验收。容器验收覆盖重建后附件持久化、数据库完整性及附件副本内容。原生 Docker Engine、Compose 提供器、Windows、Linux AMD64 和远程 HTTPS 未单独实跑。
