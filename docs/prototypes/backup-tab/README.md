# 备份页签三方向原型（UC-31）

管理台新增「备份」页签的方向对比，对应 UC-31「自动备份站点数据到云盘」。同一数据、同一组任务，三种信息组织。

## 打开方式

浏览器直接打开 `index.html`。三方向在同页纵向并列，深浅主题右上角切换。每方向顶部「场景」切换失败/成功/进行中/未配置等形态。按钮、字段、归档清单可点，不触达服务端。

## 方向

- **A · 状态面板 + 处理队列**：度量瓦片 +「需要处理」行，配置在底部。借审美 031 概览；把低频巡检任务做成了仪表盘。
- **B · 行式对象（推荐）**：备份作为一个能力对象，状态、目标、计划、操作全是同构行。借审美 030；第一眼直接回答「上次成没成」，零新范式。
- **C · 清单 + 检查器**：左列「自动备份」+ 最近归档，右栏检查器。借审美 031 主从；归档成为一等对象，但恢复由 Agent 操作时逐片明细对管理员过剩。
