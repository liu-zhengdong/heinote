# ⌘K 快速查找 · 三方向原型

任务：现在的「搜索范围」独占一行、用原生 `<select>`；命中词只有粗体、
埋在灰色摘要里；行距照搬紧凑档。三个方向对「范围放哪」给不同答案；
行距与命中标记为共享变量。检索逻辑、结果排序、行内信息不变。

行距（共享）：单行基准 36→40px 区间、标题与摘要 gap 3px、摘要 12.5px；
B 的两行元信息行同等放宽。命中标记用页首开关整体切换三档：加粗（现状）、
蓝字、浅底块（默认展示）。

- **A · 范围段收进输入行**（推荐）：输入行右侧一段双选，范围可见可改，
  弹层回到「输入 + 列表」两段。
- **B · 底栏命令条**：Spotlight 式头中脚骨架；范围走左下上弹菜单，
  右下给键位提示；结果行改两行元信息。
- **C · 范围是末尾动作**：默认不显示范围控件，结果末尾「在全部空间中
  搜索」展开；展开后范围变成输入框内可移除 token（Notion 搜索范式）。

`index.html` 顶栏 Tab 切换「现状 / A / B / C」，一次看一款；段内可操作
（输入、↑↓、点击范围控件）。顶栏右侧三档切换命中标记样式、切换深浅主题。
`shots.mjs` 生成 `shots/` 取证图。

数据为模拟，检索行为按 `src/features/quickfind/QuickFind.tsx` 的
`quickFind()` 同型实现。
